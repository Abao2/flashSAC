# FlashSAC 当前 checkpoint：行为与 Critic 诊断

本记录分析 `step9760`（9,994,240 transitions 的保存点），不是新训练结果。已读取确定性、native 两个 seed、幅度 .5/1.5、repeat 1/4/16、filter .1 共九组各 128 回合，以及确定性/native seed0/repeat16/filter .1 的离线 Critic 探针。未启动额外 GPU。后续新增对照的结论见第 6–7 节。

## 可以先下的结论

1. **不是机器人完全接近不了物体。** 三组每个回合都触发过手指到物体盒子的距离 ≤2 cm 的几何代理；但这不证明实际接触或抓稳。
2. **当前 native 探索产生的有效离桌经历很少。** 两个随机 seed 合计 256 回合：7 回合曾离桌，只有 1 回合触发原任务 >10 cm 抬升标志，0 个目标成功、0 个持续抬升近掌几何代理。不能把偶尔抬起等同于稳定抓取。
3. **常见状态中，Q 对动作的差异小、奖励项传给 Actor 的原始参数梯度明显弱于熵项。** 这是当前自身采集数据也支持的线索，不再仅来自官方策略的分布外轨迹。
4. **当前常见状态并没有明显的 TD 上界裁剪。** 起点 top-five-atoms 质量很高，但重新计算的目标越界质量为 0。不能再用“Q 接近 5”直接解释为“当前普遍饱和”。新增 repeat16 数据在罕见 >2 cm 阶段检测到较强个别目标裁剪，见第 7 节；这与“普通状态没有普遍裁剪”不矛盾。
5. **尚不能认定 Q 动作排序错误，或熵系数就是主因。** 新增两轮首动作配对检查已完成，但目前对微小局部动作差异的检验精度不足，而且全部回合仍有未知 timeout 尾项，详见第 8 节。原始梯度不是实际 Adam 更新，探针的 BN 批次组成也不是历史 replay。

## 4. 下一步能区分哪些原因

- **探索幅度/持续性对照**：若保持 checkpoint 不变，仅改采样就显著增加有效离桌/持续握持经历，支持数据覆盖问题；仍不能证明 Actor/Q 更新没有问题。
- **首动作配对回报测试**：若可检测的实际回报差异存在而 Q 排不出，才更支持估值错误。若实际差异也小，则起点 Q 小差异可能合理。首动作短暂、未来策略还不会抓取，效应可能很弱；未排出差异不等于 Q 正确。
- **同 checkpoint、不同 BN 批次组成的重复探针**：量化 Q/熵梯度比是否稳定；现值不能代替训练 replay 更新统计。
- **更早 checkpoint + 全部高奖励事件**：区分“历史阶段裁剪过”与“当前普通状态正在裁剪”。

首动作测试必须继续使用当前策略独立高斯采样，不能用官方策略接管；native cached-noise 行为与 SAC 更新中的独立采样目标策略不是同一个轨迹分布。600 步回报存在未知 timeout 尾项，不能将有限回报直接冒充精确 soft Q。

## 5. 当前结论强度

**已观察到**：确定性策略未形成离桌动作；当前 native 探索的有效抬升数据极稀少；常见状态 Q 动作差异小；这些离线批次上 Q 参数梯度比熵项弱；当前普通状态目标越界质量很低。

**仍未证明**：Q 小差异是否错误、降低 α 是否改善真实任务、LSTM 是否必要、原训练失败是否主要由上界/探索/记忆中的某一个因素造成。

离线梯度使用 FP32、无 optimizer、无 AMP、无更新后权重投影；Q 用 inference BN，Actor 用混合当前/下一状态的 training BN。采样按阶段平衡而非按历史 replay 比例。所有“梯度主导”解释必须保留这些限制。

以现有配对 SD 粗略估计，仅要让95% CI半宽缩到 Q 预测的约.0006，需要约1,150–1,340个配对重复，而非目前64个。这只是固定方差近似，不是自动追加预算的理由，更不是包含统计功效要求的正式样本量设计。当前检验对这样微小的首动作差异明显精度不足。

### 8.3 uniform 必须分别看

| 干预 | Q 预测相对 mean | 实测600步 soft差 | 未校正95% CI |
|---|---:|---:|---:|
| seed0 的 uniform动作 | +.000031 | −.014976 | [−.037180, +.007228] |
| seed1 的另一 uniform动作 | −.000515 | +.010450 | [+.002944, +.017955] |

seed1 的这一动作出现了**Q 排名与有限回报排名相反的线索**，名义区间不含0。但它是多个对照之一、没有多重比较校正，也还没有用相同 uniform 首动作配新的 continuation seed 重复确认；不能直接宣布严格的真实 Q 排序错误。

尤其是：要使这项有限回报差与 Q 预测相符，只需未知末态软价值差约−4.56，因为 .99^600=.002405。这个末态差没有测量或严格界定，因此 timeout 尾项足以成为必须保留的解释。

### 8.4 绝对数值存在较大差距，但不能偷换成已测精确无穷期误差

mean 首动作 Q≈4.676394；实测600步 soft return 平均为seed0的3.517059、seed1的3.507921，相差约1.1593/1.1685。两轮的基准归一化折扣环境奖励约1.2487/1.2389，其余约2.268是熵累计。

若要仅靠未知尾项填补绝对差距，600步末态的平均软价值需约 **482/486**。这是值得进一步检查 Critic 数值自洽性、BN训练/推理差异和学习滞后的量级异常线索。但5只是当前网络的表示上界，并不是已经证明的环境真实价值上界，因此不能把“Q support到5”当作真实尾项的严格上界来偷做误差证明。

例如“若末态价值在5左右，尾项只有约.012”可以作为量级敏感性检查，但不能当作已经测到的尾项。另一方面，即使约.012对绝对值1.16很小，对局部首动作预测差.0003–.0006却并不小。**绝对估值偏移与动作排序质量也不是同一个问题：共同偏移不一定改变 Actor 的动作梯度。**

### 8.5 本轮能支持的结论

- 起点梯度正负干预的实际效应很小，64配对重复尚不能分辨；“没有显著差异”不证明真实Q平，也不证明Critic准确。
- seed1某个较大的uniform首动作有有限回报反排序线索，应固定该动作做独立重复，而不是把两个不同uniform动作池化。
- 绝对Q和有限soft return有明显量级差，需要额外的自洽性/尾项分析；当前不能把它简化成已证明的环境接口错误或某个唯一训练失败原因。
- 所有分支0成功、全timeout，也再次说明当前后续策略没有形成完整搬运，改变单个起点动作没有直接解决动作链。

本次仅分析已经完成的文件，未启动额外GPU。后续训练是新的实验，不能把这些冻结checkpoint诊断误写成其学习结果。
