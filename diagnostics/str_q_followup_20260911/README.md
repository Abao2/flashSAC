# FlashSAC / STR：Q 与动作收益补充诊断

状态：**本轮补测完成；训练失败的唯一根因尚未确定。** 没有开始训练，没有修改生产 reward、网络、控制器、curriculum 或 checkpoint。

## 先看结论

1. **不能继续把“wrapper 接错”当作已经确认的解释。** 此前同动作对照中，原生 Lab 与 wrapper 的 59 个字段一致，覆盖 goal 命中、真正终止和超时；控制公式到 PhysX target 的差值也为 0。这只覆盖已测配置和轨迹，不等于所有 Gym/DR 场景都已证明。
2. **本轮没有验证出“Q 越高，后续实际表现就稳定越好”。但也没有充分证据宣布 Q 学错了。** 所有 15 个非重复动作对照的有限 raw/n=3-soft 回报差，环境分组的描述区间都跨 0；许多方向随后续噪声改变而反转。单步扰动的影响太小、长时回报波动和未知尾项太大，当前测试不能可靠判定优劣。
3. **“熵项整体压过 Q，所以 Actor 不学”不受本轮局部梯度证据支持。** 熵梯度范数只有 Q 项的约 1.5%–6.4%，总梯度与 Q 项方向余弦 >0.998；tanh 有衰减但不是所有梯度消失。不是实际 Adam 更新或全部 replay 分布的证明。
4. **发现可测的训练/执行策略差异，值得定向验证，而不是直接认定为 bug。** 三份真实 replay batch 中，训练 BN 与执行 BN 的均值动作平均绝对差 0.036–0.041；约 8.2%–9.3% 的动作分量差 >0.1。没有做这两套动作的物理行为对照，不能说它导致训练失败，也不能据此直接删 BN。

因此，现在没有依据把原因直接归结为缺 LSTM、熵太大、Q 一定错误，或继续训练一定能解决。已把若干泛泛猜测变成了可复核的测量；**尚未完成因果定位**。

## 本轮实际跑了什么

- 模型：冻结 500M checkpoint，full STR arm1 / noDR / n=3；KUKA + Sharpa，不是 Wuji。
- 完整资产池保留；本批初态为 32 个环境。固定 tolerance = 0.02905653603374958。
- 在同一批初态第 0 / 60 / 120 步分别干预；仍处于首回合的环境为 32 / 28 / 21。
- 七分支：原均值动作、原均值动作重复、零动作、机械臂 Q+/Q−、手 Q+/Q−。
- 只改变当前一次动作；此后运行冻结策略，使用三组共同 Gaussian 噪声，最多继续 600 步。Q+/Q−用实际测得的 Q 差解释，而非仅靠分支名字。
- 总计 63 个向量 rollout 分支、2,016 行记录，其中 1,701 行是有效首回合配对；其余因参考时首回合已结束而不纳入，不记作失败。
- 正式动作对照耗时 1,086.6 秒，约 18.1 分钟，含仿真初始化。重复基线另约 6.3 分钟。
- 三个噪声 seed 不是三个训练 seed，也不是增加三倍独立初态。

每个分支 hard reset 后恢复原物理参数并重放相同前缀。64 次物理检查：17 组参数最大差全为 0，joint/body 顺序均相同；63 个分支干预前 RNG 均一致，状态最大绝对差 6.71e-8，低于 1e-5 门限。原模型内存 digest 与四份 checkpoint 文件 SHA256 前后不变。仿真已退出，未留下训练进程。

## Q 对照的具体例子

同一个阶段，先对每个环境计算“候选动作 − 原动作”，再对三个噪声 seed 求平均，最后对环境汇总。下面的有限收益不是原始 TensorBoard episode reward，也不是完整训练 Q 的精确值。

| 状态 / 干预 | 实测平均 ΔQ | 后续 n=3-soft 回报差 | 环境分组的描述区间 |
|---|---:|---:|---:|
| 起点，机械臂 Q+ | +0.000324 | +0.00396 | [-0.0563, +0.0658] |
| 第60步，机械臂 Q+ | +0.002331 | +0.02415 | [-0.0746, +0.1284] |
| 第120步，机械臂 Q+ | +0.003231 | -0.02078 | [-0.1106, +0.0827] |
| 第120步，手 Q+ | +0.001652 | -0.02204 | [-0.1119, +0.0778] |

例如起点机械臂 Q+ 的三个后续噪声组，回报差分别是 -0.01777、-0.09819、+0.12784：**Q 评分增加是明确的，实际有限收益的方向却不稳定。** 这不是“证明 Q 正确”，也不能只挑负数说“证明 Q 错误”。

另有值得保留的局部现象：第60步机械臂 Q− 的三组平均 goal 增量为 +0.786 / +0.500 / +0.321；其三组 raw 折扣回报差也均为正（+38.83 / +159.94 / +4.95），但按环境平均后的 raw 增益 +67.91，其描述区间为 [-0.40, +145.89]，环境中位数仅约 +0.00087，说明均值受少数环境大变化影响。所有分支的 raw 和 n=3-soft 回报描述区间仍跨 0。多到达几个 goal 不等于更高的总回报或更高的完整任务成功率，不能单靠此项定罪 Q。

重复原动作的第60/120步对照，所记录的回报、goal 数和终止类别差均为 0；第0步仍有一组微小物理分歧扩展成有限回报差，n=3-soft 单配对最大绝对差约 0.03771。这个数只是本次经验参照，不是噪声上界或显著性阈值。

## 为什么本轮仍不能宣称找到根因

- 只改变一个控制步，机械臂 Q 扰动对应的关节目标增量量级约 0.005 rad；不是连续执行更好的动作，更不是一次真实 Actor 参数更新。
- 不同动作会改变 goal/reset 事件，进而改变环境随机数的消耗顺序；共用策略 Gaussian 噪声不代表以后每一个随机目标仍完全一样。
- 超时和诊断时长截止有未知后续价值。不能用当前 Q 自己补尾项再声称验证了 Q，也不能只挑双方都真正终止的样本作主结论。
- 实际训练 n=3 的 reward 累计与 bootstrap 熵项，与每步扣熵的 dense-soft 定义不同。因此保留 raw、dense-soft、n=3-soft 三列；本轮冻结 Gaussian 后续也不等于历史 Zeta replay 策略。
- 描述区间按环境分组，不把噪声重复算成独立样本；资产混合、环境 RNG 的潜在相互依赖及多项探索性比较仍在。不能当作确认性统计检验。
- “抬起”标志和物体高度不证明已抓稳；goal 数不是完整 50-goal 成功率。
- Actor 有梯度并沿 Q 优化，不代表 Q 的方向对实际任务有帮助；训练/执行 BN 有差异，也不代表差异一定有害。

## 下一项最小的有判别力验证（尚未执行）

先验证**训练模式与执行模式之间的归一化差异是否真的伤害行为**：冻结权重、事先固定真实 replay 的 BN 参考统计，对照原执行统计，在匹配初态下比较掉落与到达目标。不能在单环境里直接开 train-mode BN，也不能直接改生产训练配置。

若没有行为改善，就降低这个解释的优先级；若改善明显，再在实际训练更新上验证其原因。这个候选不是本轮已经确认的修复，也不据此续跑数亿步或新增 LSTM。
