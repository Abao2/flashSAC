# 500M Q probe 冒烟测试：解释边界

状态：**协议冒烟完成，不是 Q 准确性结论。** 来源为同目录 `summary.json` 与 `control_0_*.npz`；8 个随机初始状态，prefix=0，7 个动作分支，每条最多 30 步（0.5 秒）。没有重新训练。

- 初始可见物理／控制／goal／tracker 状态与 Python、NumPy、Torch CPU/CUDA RNG 均通过配对检查；最大可见状态误差 `2.98e-8`。第一步 mean 与 mean_repeat 的动作、应用目标、关节位置逐元素一致。
- 之后的 mean_repeat 仍出现数值／仿真传播差异：有限 soft return 差值绝对值均值 `0.00029705`、最大 `0.00063067`；最高物体高度差最大 `0.00387853 m`。不能把这种量级的单次差异当成动作因果效应。
- 56 条分支轨迹全部被诊断时长截断，**没有真正终止样本**。未知尾部折扣 `0.99^30=0.73970037`；这些结果不能校准真实 Q，更不能用于判定“Critic 错了”。

仅作为经验参照，用 mean_repeat 的本次最大绝对差 `0.00063067` 过滤有限回报差异：

| 单步干预 | 有限回报差超过重复基线最大差的状态数 | 其中 Q 与有限回报变化同向 |
|---|---:|---:|
| zero | 6/8 | 6/6 |
| arm Q+ | 3/8 | 2/3 |
| arm Q− | 4/8 | 2/4 |
| hand Q+ | 0/8 | 无可解释样本 |
| hand Q− | 1/8 | 1/1 |

**这个阈值是 8 个状态的一次重复观测，不是噪声上界、置信区间或显著性检验。** zero 是将 29 维归一化动作置零（手指绝对目标趋向关节中点），不是“保持原姿态”。它的粗动作差异不能替代抓稳／搬运证据。所有分支本段 goal 增量均为零。

控制信号确实传入了仿真：arm Q+ 相对 mean 的应用目标 L2 差均值 `0.00415291 rad`，第一步关节位置 L2 差均值 `0.00091333 rad`；hand Q+ 分别为 `0.01152335 rad` 与 `0.00186777 rad`。这证明本次扰动不是被接口完全吞掉，不证明控制长期正确。

正式 600 步 probe 应检查：prefix 0/60/120 的配对留存与物体分布；该 prefix 的 mean_repeat 差；双方均真正终止的样本；其余样本的未知尾部。`0.99^600=0.00240501` 比 30 步小，但仍可能比约 `0.0003–0.0006` 的单步 Q 差大，因此排序一致率仍不是 Q 正确率。不能为了增加样本而放宽 `1e-5` 状态门限。
